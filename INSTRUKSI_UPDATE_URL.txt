LANGKAH 1: Update URL Backend
-----------------------------

3. Tunggu sampai muncul tulisan "Selesai!"

LANGKAH 2: Push ke GitHub
-------------------------
1. Buka folder yang sama di File Explorer.

2. Double klik file:
   push-ke-github.bat   (kalau belum ada, buat dulu atau pakai cara manual)

   Atau lakukan manual:
   - Klik kanan di folder kosong → Git Bash Here (kalau ada)
   - Atau buka PowerShell dan ketik:
     git add .
     git commit -m "Update backend URL ke Railway baru"
     git push
